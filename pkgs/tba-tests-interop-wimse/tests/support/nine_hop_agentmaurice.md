# AgentMaurice File Tool binding

Start the existing network-isolated AgentMaurice lab with `TBA_AGENTMAURICE_NINE_HOP=1`. Mount the generated `keys/rich.jwks.json` read-only at `/input/rich.jwks`, alongside the existing mount for `keys/peer.jwks.json`. Use `sh /fixture/nine_hop_agentmaurice_lab.sh` after the NATS boot gate. The wrapper retains the pinned release checks and adds the exact Research workflow grant, Research issuer trust, and File Tool WPT audience.

Pass the deployment ID from `/tmp/test-id` as `context["agentmaurice_file_tool_agent"]` when loading peer bindings. `build_bindings` registers `verify_wimse_proof` for the `file-tool` role. Call it through the normal `/files/read` handler on port 5063. The internal workflow invocation on port 5000 carries the original WIT, WPT and transaction token. It omits `X-Test-Case` so the shared capture associates only the original File Tool request with hop nine.

AgentMaurice v2.2.18, commit `c9ae5757e9d97ec8fa6b9fc9e6b835c63eba770b`, authenticates the Research WIT and WPT, including the proof's WIT and transaction hashes, and applies its workflow grant. The adapter selects the exact File Tool audience from the proof presented to AgentMaurice and checks the Domain B token signature, issuer, audience, workload binding, narrowed scope and file context. The fixture File Tool handler performs the protected read after successful native admission. The `text-stats` execution gives the adapter a synchronous receipt of admission. The protected file content remains in the File Tool fixture.

The local pinned B_CHAIN smoke run used Docker with `--network none` and NATS in the same network namespace. The pinned driver succeeded, both native workflow calls returned HTTP 200, AgentMaurice logged `wit+wpt` acceptance for `wimse://rich.ietf127.example/agent/research`, and the File Tool journal recorded one HTTP 200 read. The test used a local Docker exec transport for the internal workflow API. Hosted qualification still requires the shared wire oracle and per-assignment reconciliation.
